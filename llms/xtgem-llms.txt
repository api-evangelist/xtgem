# XtGem

> XtGem is a visual mobile website builder operated by UAB XtGem of Vilnius,
> Lithuania. It lets anyone build and host mobile sites on *.xtgem.com
> subdomains (10M+ sites hosted) using a drag-and-drop builder and the XtScript
> templating language. XtGem publishes no public developer API, webhooks, or
> SDKs; its only first-party open-source project is the XtFramework PHP
> framework on GitHub.
